# JobMate 사용자 평가 안내문 (평가자에게 전달)

작성일 2026-11-25 · 진행자 반재영

## 1. 어떤 평가인가요?
JobMate는 이력서·자기소개서를 붙여 넣으면 어울리는 직무를 추천하고, 선택한 직무 기준으로 서류를 점검·보완해 주는 학습용 프로그램(종합 프로젝트)입니다. 15분 정도 직접 써 보시고 설문에 답해 주시면 됩니다. **프로그램을 평가하는 것이며 평가자 본인을 평가하지 않습니다.** 불편했던 점은 그대로 말씀해 주시는 것이 가장 큰 도움입니다.

## 2. 개인정보 안내 (꼭 읽어 주세요)
- 프로그램은 **진행자의 PC에서만** 실행되며 인터넷에 공개되지 않습니다.
- 서류를 붙여 넣으면 **전화번호·이메일·주민번호·카드번호는 자동으로 가려진 뒤** 저장·분석됩니다. 단, **이름·학교명·회사명은 가려지지 않습니다.**
- 실제 이력서가 부담되면 **가상의 내용(예: 가상 인물)** 으로 입력하셔도 됩니다. 이 경우에도 평가는 가능합니다.
- 입력한 서류는 평가 분석 목적으로만 쓰고, 결과보고서에는 **서류 원문을 싣지 않고** 점수·평균만 씁니다. 의견은 이름 없이(A, B…) 인용합니다.
- 언제든 중단할 수 있고, 평가 후 **기록 삭제를 요청**하시면 삭제합니다.
- AI(LLM) 기능은 진행자 PC의 로컬 모델 또는 외부 AI 연결 여부에 따라 달라집니다. 외부 AI가 연결되어 있다면 **가려진 문장 일부가 해당 회사로 전송**될 수 있으니 진행자에게 어떤 모드인지 먼저 물어보세요(화면 상단 "AI:" 표시).

**동의 확인** (진행자가 구두로 확인 후 체크)
- [ ] 위 내용을 이해했고 평가에 참여하는 데 동의합니다.
- [ ] 입력할 서류: 실제 서류 / 가상 서류

## 3. 진행 순서 (약 15분)
1. 「샘플 불러오기」는 누르지 말고, 본인(또는 가상)의 이력서·자소서를 각 칸에 붙여 넣습니다.
2. **직무 추천 받기** → 추천 Top 3를 보기 **전에 본인이 생각한 직무를 말해 주세요**(진행자가 기록).
3. 추천 이유와 근거를 읽어 보세요.
4. 직무를 하나 골라 **이 직무로 점검하기** → 지적된 문장이 맞는지 확인합니다.
5. **문장 보완 제안 받기** → 제안 중 하나를 실제로 고쳐 써 보세요.
6. (선택) 지원하려는 공고가 있다면 **채용 공고로 점검**에 붙여 넣어 보세요.
7. 고친 서류로 다시 추천→점검하여 점수 변화를 확인합니다.
8. 설문에 답합니다.

## 4. 설문 (1 전혀 아니다 ~ 5 매우 그렇다)
| 번호 | 문항 |
|---|---|
| Q1 | 추천 1순위가 내가 생각한 직무와 같았다 / Top 3 안에 있었다 (예·아니오) |
| Q2 | 추천 이유(보유·부족 역량, 근거)가 이해되었다 |
| Q3 | 점검에서 지적한 문장이 실제로 고칠 만한 부분이었다 |
| Q4 | 점검 점수가 내 느낌과 비슷했다 |
| Q5 | 보완 제안이 문장을 고치는 데 도움이 되었다 |
| Q6 | 근거 가이드(출처 표시) 덕분에 조언을 믿을 수 있었다 |
| Q7 | 제안 중 **사실과 다른 내용**이 있었다 (예·아니오, 있었다면 무엇) |
| Q8 | 화면 사용이 어렵지 않았다 |
| Q9 | 이 도구를 다시 쓰고 싶다 |
| Q10 | 가장 불편했던 점 / 있었으면 하는 기능 (서술) |

## 5. 진행자용 기록과 집계
1. `samples/survey_template.csv`를 복사해 평가자별로 한 줄씩 입력합니다(열: rater, field, thinkJob, top1, top3, scoreBefore, scoreAfter, q2~q9, comment). 빈 칸은 비워 두면 응답 없음으로 처리됩니다.
2. 집계: `node tools/analyze_survey.mjs 응답파일.csv`
3. 결과(달성/미달 포함)를 결과보고서 4.6절("미실시, 모의 평가로 대체" 문구를 실제 결과로 교체)에 **그대로** 기록하고, 모의 평가(예비)와 구분해 적습니다.
4. 평가용 데이터가 쌓인 DB(`data/jobmate.db`)는 평가 종료 후 삭제하거나 평가자 요청 시 해당 기록을 지웁니다.

## 6. 진행자 사전 점검표
- [ ] `npm start` 실행, 상단 상태줄에서 검색·AI 모드 확인(외부 AI 연결 여부를 평가자에게 고지)
- [ ] 평가자마다 **새 브라우저 창(시크릿 창 권장)** 사용 → 이전 평가자의 기록이 보이지 않음
- [ ] 화면 녹화·캡처는 평가자 동의 후에만, 서류 내용이 보이지 않는 범위로
- [ ] 평가자가 막히는 지점과 말한 의견을 그대로 메모(고쳐 주거나 설명해 주지 않고 관찰)
