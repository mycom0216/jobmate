# JobMate 사용자 평가 계획 · 설문지

작성일 2026-11-25 · 작성자 반재영 · 실시 예정 12/08~12/19 (일정표 4단계 테스트)

> 사전 단계로 가상 지원자 6명을 통과시킨 **모의 평가**를 완료했습니다(`JobMate_모의평가결과.md`). 모의 평가는 객관 지표와 결함 탐지용이며 이 계획의 설문(주관 평가)은 실제 사람이 해야 합니다.

## 1. 목적
가상 데이터로만 측정한 추천 정확도와 점검 유용성을 **실제 사용자**로 확인하고, 결과를 결과보고서(4.4절)와 개선 목록에 반영합니다.

## 2. 대상과 방법
| 항목 | 내용 |
|---|---|
| 대상 | 지인·과정 동기 3~5명 (취업 준비 중이거나 이력서를 써 본 사람) |
| 방법 | 본인 문서(또는 연습용 가상 문서)를 직접 입력 → 추천 → 점검 → 보완까지 한 번 사용 → 설문 |
| 소요 | 약 15분 |
| 장소·기기 | 내 PC에서 서버 실행, 평가자는 옆에서 직접 조작(외부 공개 안 함) |
| 윤리 | 실제 이력서를 쓰면 개인정보가 DB에 마스킹 후 저장됨을 사전 안내, 평가 후 요청 시 기록 삭제, 연락처·실명은 받지 않음 |

## 3. 진행 순서
1. 목적과 개인정보 처리 설명, 동의 확인
2. 평가자가 문서를 직접 붙여 넣고 「직무 추천 받기」
3. 추천 직무를 보고 **본인이 생각한 직무와 같은지** 먼저 기록 (설문 Q1)
4. 점검 결과의 지적 사항이 맞는지 확인
5. 보완 제안을 읽고 실제로 고칠 문장을 하나 고쳐 보기
6. 같은 직무로 재점검해 점수 변화 확인
7. 설문 작성

## 4. 설문 (5점 척도: 1 전혀 아니다 ~ 5 매우 그렇다)
| 번호 | 문항 | 응답 |
|---|---|---|
| Q1 | 추천 Top 3에 내가 생각한 직무가 있었다 (예 / 아니오, 1순위 일치 여부) | |
| Q2 | 추천 이유(보유·부족 역량, 근거)가 이해되었다 | 1 2 3 4 5 |
| Q3 | 점검에서 지적한 문장이 실제로 고칠 만한 부분이었다 | 1 2 3 4 5 |
| Q4 | 점검 점수가 내 느낌과 비슷했다 | 1 2 3 4 5 |
| Q5 | 보완 제안이 문장을 고치는 데 도움이 되었다 | 1 2 3 4 5 |
| Q6 | 근거 가이드(출처 표시) 덕분에 조언을 믿을 수 있었다 | 1 2 3 4 5 |
| Q7 | AI·빈칸 틀 제안에 사실과 다른 내용이 있었다 (있었다면 무엇) | 예 / 아니오 |
| Q8 | 화면 사용이 어렵지 않았다 | 1 2 3 4 5 |
| Q9 | 이 도구를 다시 쓰고 싶다 | 1 2 3 4 5 |
| Q10 | 가장 불편했던 점 / 있었으면 하는 기능 | 서술 |

## 6. 분석 방법과 성공 기준
| 지표 | 계산 | 기준(목표) |
|---|---|---|
| 추천 일치율 | Top-1 일치 수 / 평가자 수, Top-3 포함 수 / 평가자 수 | Top-3 포함 60%↑ |
| 유용성 | Q3·Q5 평균 | 3.5↑ |
| 신뢰성 | Q6 평균, Q7 "있었다" 비율 | Q6 3.5↑, Q7 0건 목표 |
| 사용성 | Q8 평균 | 3.5↑ |
| 점수 변화 | 수정 전후 점검 점수 차이 | 평균 +5점↑ |

> 표본이 3~5명이라 **통계적 일반화는 불가능**합니다. 결과보고서에는 평균과 함께 개별 의견을 그대로 적고, 한계(소규모·지인 편향)를 명시합니다. 기준 미달이면 감추지 않고 원인과 개선 계획을 씁니다.

## 7. 결과 반영 절차
1. 불편·오류 의견 → 이슈 목록 작성 → 우선순위(재현 가능·영향 큼) 순 수정
2. 수정마다 테스트 추가, 테스트 결과서 6장에 결함 표로 기록
3. 개선 전후를 결과보고서 4.4·5장에 반영
