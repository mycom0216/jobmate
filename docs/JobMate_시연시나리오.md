## 0. 사전 준비 (발표 10분 전)
- [ ] `npm start` 로 서버 실행 후 <http://127.0.0.1:5400> 접속, 상단 상태줄에서 검색·AI 모드 확인
- [ ] 로컬 AI(Ollama kanana2:3b)를 쓸 경우 한 번 호출해 모델을 미리 깨워 둠(첫 호출이 느림)
- [ ] 시연 도중 AI 응답이 길어질 수 있으니 **「AI로 다듬기」 체크를 끈 버전**도 준비
- [ ] 브라우저 새 창(기록 비어 있는 상태), 확대 125%
- [ ] 백업: 시연 영상(화면 녹화)과 `docs/images/ui-*.png` 캡처
- [ ] 예비: 샘플 문서는 「샘플 불러오기」(가상 인물 '홍길동')를 사용 — **본인 실제 이력서는 화면에 띄우지 않음**

## 2. 예상 돌발 상황과 대응
