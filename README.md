# JobMate — RAG 기반 직무 추천 · 이력서/자소서 점검 시스템

이력서와 자기소개서를 붙여 넣으면 **① 어울리는 직무 Top 3를 근거와 함께 추천**하고, **② 선택한 직무 기준으로 8개 항목(100점) 점검**하며, **③ 문제 문장을 직무에 맞게 고쳐 쓰도록 보완 제안**하고, ④ 지원할 **채용 공고의 자격요건·우대사항을 내 서류와 한 줄씩 대조**합니다. (인공지능 응용 시스템 개발 종합 프로젝트, 작성자 반재영)

- **근거 표시(RAG)**: 추천·점검·보완마다 참고한 지식 청크(예: BACKEND-02)를 보여 줍니다.
- **환각 방지**: AI가 만든 문장에 원문에 없는 숫자·기술명이 있으면 버리고 빈칸 채우기 틀로 대체합니다.
- **개인정보 보호**: 전화·이메일·주민·카드번호는 저장·AI 전송 전에 가립니다.
- **AI 없이도 동작**: 추천·점검은 AI를 쓰지 않고, 보완은 AI가 없으면 빈칸 틀을 제공합니다.

## 실행
Node.js 24 이상만 필요합니다(npm 설치 없음).
```bash
npm start
```
브라우저에서 <http://127.0.0.1:5400> (Windows는 `시작하기.cmd` 더블클릭). 「샘플 불러오기」로 바로 시연할 수 있습니다.

### AI 연결(선택)
`.env.example`을 `.env`로 복사해 키를 채웁니다. 자세한 값은 파일 주석 참조. 키가 없고 로컬 Ollama(`kanana2:3b`)가 있으면 그것을, 둘 다 없으면 규칙 기반으로 동작합니다. 외부 AI를 쓰면 **마스킹된 문장 일부가 해당 회사로 전송**됩니다.

## 테스트·평가
```bash
npm test            # 자동 테스트 43개
npm run eval        # 직무 추천 정확도(쉬운 26건·어려운 10건, 가중치 비교)
node tools/simulate_eval.mjs --md   # 모의 사용자 평가(가상 지원자 6명, 실제 사용자 평가 아님)
node tools/analyze_survey.mjs 응답.csv   # 실제 사용자 평가 설문 집계(양식: samples/survey_template.csv)
node tools/shots.mjs   # 화면 캡처(서버 실행 중)
python tools/make_erd.py   # ERD 이미지
```
> 평가 문서는 직접 만든 가상 데이터이므로 실제 정확도를 보장하지 않습니다(docs의 테스트 결과서 참조).

## 한계
직무 지식은 작성자가 정리한 예시 기준이라 실제 공고와 다를 수 있고, 로그인·파일 업로드·공고 연동이 없으며, Claude·ChatGPT·임베딩 검색은 이 환경에서 실측하지 못했습니다.
